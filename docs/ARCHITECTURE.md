- `Sources/FinanceCore`: Swift Package بلا اعتماديات، يعمل على iOS وmacOS وLinux. كل المنطق المالي هنا ومغطى بالاختبارات.
- `App/M9rofi`: واجهة SwiftUI، التخزين المشفر، Face ID، الإشعارات، App Intents، استيراد الملفات.
- `Ledger` نوع قيمة (struct) → حتمي وقابل للاختبار بالكامل.

## قواعد الاحتساب (`Aggregator.effect`)

| الحالة | الأثر |
|---|---|
| مستبعدة يدوياً / ملغاة (reversed) / رسالة عكس | لا شيء |
| في قائمة المراجعة | غير محتسبة، تظهر كـ «قيد المراجعة» |
| معلقة | غير محتسبة، تظهر كـ «معلقة» |
| تحويل داخلي / سداد بطاقة ائتمانية | لا شيء |
| سحب نقدي | «سحب نقدي» منفصل (إعداد: احتسابه كمصروف) |
| تحويل صادر لطرف آخر | مصروف في «التحويلات المالية» (إعداد قابل للتغيير) |
| تحويل وارد من طرف آخر | «تحويل وارد» — ليس دخلاً |
| راتب / دخل صريح | دخل |
| استرداد | يُطرح من مصروفات تصنيف الشراء الأصلي في فترة الاسترداد |
| شراء / فاتورة / رسوم | مصروف |

صافي المصروفات = إجمالي المصروفات − المستردات. صافي التدفق النقدي = الدخل − صافي المصروفات.

## منع التكرار

1. **مطابق**: نفس `sourceRecordID` (تجزئة نص الرسالة، مرجع الكشف، معرّف Open Banking). يبقى محفوظاً حتى بعد حذف العملية.
2. **عبر المصادر**: نفس المبلغ والاتجاه، حساب/بطاقة غير متعارضين، فرق زمني ≤ 15 دقيقة (أو ≤ 4 أيام إذا كان أحدهما بلا وقت مثل الكشف)، تشابه اسم الجهة. مرجع بنكي متطابق = دمج مباشر.
   - مصدران من نفس النوع لا يُدمجان إلا معلقة→مكتملة (عمليتان حقيقيتان متطابقتان من SMS تُحتسبان معاً).
   - نتيجة ≥ 0.6 ومرشح وحيد → دمج. نتيجة غامضة أو أكثر من مرشح → قائمة المراجعة وغير محتسبة.

## التحويلات الداخلية

- رقم الحساب المستفيد (آخر 4 أرقام أو IBAN) يطابق حساباً للمستخدم → داخلي.
- خصم في حساب + إيداع بنفس المبلغ في حساب آخر للمستخدم خلال 6 ساعات (3 أيام للكشوف) → زوج داخلي.
- شحن محفظة بالبطاقة (شراء لدى «BARQ» + إيداع في Barq) → داخلي.
- تحويل باسم المستخدم دون طرف مقابل → مراجعة.

## الأمان

- AES-256-GCM (CryptoKit) للملف كاملاً، المفتاح في Keychain بفئة `AfterFirstUnlockThisDeviceOnly` (لا يُزامن ولا يدخل النسخ الاحتياطي).
- حماية ملف iOS `completeUntilFirstUserAuthentication`، والمجلد مستثنى من النسخ الاحتياطي.
- Face ID / رمز الجهاز عند الفتح وعند العودة من الخلفية، مع تمويه الشاشة في مبدّل التطبيقات.
- لا يُخزَّن إلا آخر 4 أرقام للبطاقات والحسابات. لا CVV ولا أرقام كاملة.
- لا يوجد أي طلب شبكة في التطبيق. حذف كل البيانات يحذف الملف والمفتاح والإشعارات.

## قابلية التوسع

- مصدر جديد = Adapter يُنتج `RawRecord`. لا تعديل على المحرك.
- بنك جديد = حساب + أسماء المرسلين + قالب Regex اختياري.
- التخزين خلف `EncryptedLedgerStore`؛ الانتقال إلى SQLite/SQLCipher ممكن دون تغيير المحرك عند تجاوز عشرات الآلاف من العمليات.
- `LedgerState` بفك ترميز متسامح: الحقول الجديدة تأخذ قيماً افتراضية.
