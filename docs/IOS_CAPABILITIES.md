# فحص إمكانيات iOS والربط المالي في السعودية

تاريخ الفحص: أكتوبر 2026. الحالة: ✅ متاح ومُنفّذ · 🟡 متاح بشروط · ⛔ غير متاح.

## 1. مصادر البيانات

| المصدر | الحالة | الطريقة الرسمية | القيود |
|---|---|---|---|
| رسائل SMS البنكية | ✅ | Shortcuts → Personal Automation → **Message** (المرسل/يحتوي) → إجراء `Log Bank Message` من التطبيق (App Intent) | iOS لا يمنح أي تطبيق صلاحية قراءة الرسائل. `ILMessageFilterExtension` مخصص لتصفية رسائل المرسلين المجهولين فقط ولا يسمح بحفظ المحتوى أو مشاركته — غير صالح. الأتمتة تعمل فقط للرسائل الجديدة بعد إعدادها. |
| Apple Pay | ✅ | Shortcuts → Automation → **Transaction** (Wallet، iOS 17+) → إجراء `Log Apple Pay Payment` بالتاجر/المبلغ/البطاقة | يعطي التاجر والمبلغ واسم البطاقة فقط. لا يعطي رقماً مرجعياً ولا حالة التسوية. رسالة البنك تُدمج لاحقاً تلقائياً. لا يشمل الدفع بالبطاقة الفعلية أو عبر الإنترنت دون Apple Pay. |
| سجل Apple Wallet / FinanceKit | ⛔ | FinanceKit (iOS 17.4+) | يتطلب Entitlement من Apple، ويغطي Apple Card / Apple Cash / Savings في الولايات المتحدة. لا يشمل مدى أو بطاقات البنوك السعودية. |
| إشعارات التطبيقات الأخرى | ⛔ | — | لا توجد واجهة في iOS لقراءة إشعارات تطبيقات أخرى. البديل: تفعيل تنبيهات SMS في تطبيق البنك. |
| كشوف الحساب CSV | ✅ | استيراد ملف (Files / مشاركة) | اكتشاف الأعمدة تلقائياً بالعربية والإنجليزية. |
| كشوف Excel ‎.xlsx | ✅ | استيراد ملف (مكتبة CoreXLSX محلية) | الورقة الأولى فقط. |
| كشوف PDF | 🟡 | PDFKit لاستخراج النص | يعمل مع ملفات PDF النصية. الملفات الممسوحة ضوئياً بلا نص غير مدعومة. التخطيطات تختلف بين البنوك؛ الأسطر غير المفهومة تُعرض ولا تُخمَّن. |
| البريد الإلكتروني | 🟡 | استيراد ‎.eml (مُنفّذ) · Gmail API / Microsoft Graph عبر OAuth (مرحلة لاحقة) | المزامنة المباشرة تحتاج عميل OAuth خاصاً بك. نطاق `gmail.readonly` مقيد لدى Google ويعمل في وضع الاختبار للاستخدام الشخصي. |
| الإدخال اليدوي واللصق | ✅ | داخل التطبيق | — |
| Siri / الاختصارات | ✅ | App Intents: «كم صرفت اليوم»، «اسأل مصروفي» | — |

## 2. الربط البنكي المباشر في السعودية

| الجهة | الحالة | التفاصيل |
|---|---|---|
| إطار المصرفية المفتوحة (SAMA Open Banking Framework) | 🟡 | خدمات معلومات الحسابات (AIS) متاحة فقط عبر مزودي خدمة مرخصين من البنك المركزي السعودي أو ضمن بيئة ساما التجريبية. فرد أو تطبيق شخصي لا يحصل على وصول مباشر. التفعيل يتطلب: عقداً تجارياً مع مزود مرخّص (مجمّع بيانات)، خادماً لإدارة الموافقات والرموز، وموافقة المستخدم عبر البنك. |
| البنك الأهلي SNB | 🟡 | لا توجد واجهة عامة للأفراد. المتاح: SMS + Apple Pay + كشوف إلكترونية. المصرفية المفتوحة عبر مزود مرخّص. |
| Barq | 🟡 | لا توجد واجهة عامة. المتاح: SMS/إشعارات (إن أرسلت SMS) + Apple Pay + كشف/تصدير إن توفر. شحن المحفظة بالبطاقة يُكتشف كتحويل داخلي. |
| D360 | 🟡 | لا توجد واجهة عامة. المتاح: SMS + Apple Pay + كشوف. المصرفية المفتوحة عبر مزود مرخّص. |

ما هو جاهز في الكود: `OpenBankingMapper` يحوّل استجابة Transactions بصيغة نموذج موارد AIS (Accounts/Balances/Transactions، المشابه لمعيار UK OBIE) إلى سجلات موحدة، وبروتوكول `AccountInformationProvider` لتوصيل أي مزود. يجب التحقق من أسماء الحقول مقابل توثيق المزود الفعلي قبل الاستخدام.

## 3. التوصية العملية للأتمتة الكاملة دون إدخال يدوي

1. تفعيل تنبيهات SMS لكل العمليات في تطبيقات SNB وBarq وD360 (بدون حد أدنى للمبلغ).
2. أتمتة Message لكل مرسل بنكي → `Log Bank Message` (تشغيل فوري دون تأكيد).
3. أتمتة Wallet Transaction لكل البطاقات → `Log Apple Pay Payment`.
4. استيراد كشف شهري من كل بنك لسد أي فجوة (رسالة فائتة، عملية دون SMS). التكرار يُدمج تلقائياً.
5. عند توفر عقد مع مزود مصرفية مفتوحة مرخّص: تفعيل `AccountInformationProvider`.

## 4. قيود يجب معرفتها

- لا يمكن استيراد رسائل SMS القديمة تلقائياً. البديل: لصقها في شاشة الاستيراد أو استيراد كشف.
- أتمتة Message تعمل عند استلام الرسالة. إذا كان الجهاز مقفلاً قبل أول فتح بعد إعادة التشغيل، لا يمكن قراءة المفاتيح؛ لذلك الملف محمي بفئة `CompleteUntilFirstUserAuthentication`.
- صيغ رسائل البنوك تتغير. المحلل عام + قوالب Regex يضيفها المستخدم لكل بنك. الرسائل غير المفهومة لا تُحتسب وتذهب للمراجعة.
