# إعداد الأتمتة (Shortcuts)

يجب فتح التطبيق مرة واحدة بعد التثبيت ليُسجّل iOS إجراءاته.

## 1. رسائل البنوك (لكل بنك)

1. الاختصارات ← **أتمتة** ← **+** ← **رسالة (Message)**.
2. **المرسل**: اختر جهة اتصال البنك (أو احفظ رقم/اسم المرسل كجهة اتصال أولاً، مثل `SNB-AlAhli`، `Barq`، `D360`).
3. اختياري: **الرسالة تحتوي** `SAR` أو `ريال` لتقليل التشغيل على رسائل غير مالية (المحلل يتجاهل رسائل التحقق والمرفوضة على أي حال).
4. **تشغيل فوري** (Run Immediately) وإيقاف «إشعار عند التشغيل».
5. الإجراء: **مصروفي ← تسجيل رسالة بنكية (Log Bank Message)**.
   - Message = **مُدخل الاختصار** (Shortcut Input) ← المحتوى.
   - Sender = **مُدخل الاختصار** ← المرسل (اختياري، يحسّن ربط الحساب).

## 2. Apple Pay

1. الاختصارات ← **أتمتة** ← **+** ← **معاملة (Transaction)**.
2. اختر كل البطاقات في المحفظة. **تشغيل فوري**.
3. الإجراء: **مصروفي ← تسجيل دفعة Apple Pay (Log Apple Pay Payment)**:
   - Merchant = مُدخل الاختصار ← التاجر
   - Amount = مُدخل الاختصار ← المبلغ
   - Card = مُدخل الاختصار ← البطاقة/البطاقة أو البطاقة المصرفية (Card or Pass)
4. في التطبيق ← الحسابات: اكتب اسم البطاقة كما يظهر في المحفظة في حقل «اسم البطاقة في Apple Wallet».

## 3. Siri

- «كم صرفت اليوم في مصروفي»
- «اسأل مصروفي» ثم السؤال.

## 4. التحقق

- أرسل لنفسك رسالة تجريبية لا تُحتسب: استخدم شاشة **الاستيراد ← الصق الرسائل** بدلاً من ذلك لاختبار المحلل.
- **المزيد ← صيغ الرسائل البنكية**: الصق رسالة حقيقية في «رسالة تجريبية» لرؤية ما يستخرجه المحلل. إذا كان خاطئاً أضف قالباً.
- **المزيد ← الرسائل المتجاهلة**: سجل الرسائل التي اعتُبرت غير مالية (OTP، مرفوضة، ترويجية).
