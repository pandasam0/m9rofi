# مصروفي — M9rofi

تطبيق iPhone أصلي (SwiftUI) لإدارة المال الشخصي: يجمع العمليات من الرسائل البنكية وApple Pay والكشوف والإيصالات، يمنع التكرار، يميّز التحويلات الداخلية، ويحسب المصروفات بدقة. يعمل محلياً بالكامل ومشفّر.

## الهيكل

```
Package.swift                 FinanceCore (المحرك المالي، بلا اعتماديات)
Sources/FinanceCore/
  Models/                     Transaction, Account, Category, LedgerState
  Ingestion/                  SMSParser, StatementImporter (CSV/XLSX/PDF), Wallet, Email(.eml), OpenBanking
  Engine/                     Ledger (الدمج والتكرار والتحويلات), Aggregator (قواعد الاحتساب),
                              Categorizer, Insights (ميزانيات/اشتراكات/شذوذ/تنبيهات), QueryEngine (المساعد)
  Export/                     تقارير CSV و Excel
Tests/FinanceCoreTests/       48 اختباراً للدقة المالية والمحللات
App/M9rofi/                   تطبيق iOS: الواجهات، التخزين المشفر، Face ID، App Intents، الإشعارات
project.yml                   تعريف مشروع Xcode (XcodeGen)
docs/                         فحص إمكانيات iOS، البنية، إعداد الاختصارات
```

## التشغيل على الآيفون

المتطلبات: Mac مع Xcode 16+ (Xcode 26 لتفعيل نموذج Apple Intelligence المحلي)، iPhone بـ iOS 17+.

```bash
brew install xcodegen
xcodegen generate
open M9rofi.xcodeproj
```

1. Signing & Capabilities → اختر Team (حساب Apple مجاني يكفي؛ التطبيق يحتاج إعادة توقيع كل 7 أيام. حساب مطوّر مدفوع = سنة).
2. اختر جهازك ← Run.
3. في التطبيق: المزيد ← الحسابات ← أضف SNB / Barq / D360 بآخر 4 أرقام البطاقات والحسابات.
4. أعدّ الأتمتة: [`docs/SHORTCUTS_SETUP.md`](docs/SHORTCUTS_SETUP.md).
5. استورد آخر كشف لكل حساب لبدء السجل.

## حالة المراحل

| 2. ربط البنوك والمحافظ رسمياً | 🟡 محوّل Open Banking + بروتوكول المزود جاهزان؛ التفعيل يحتاج عقداً مع مزود مرخّص من ساما. Apple Pay عبر أتمتة Wallet ✅ |

## مبادئ الدقة

- لا تُحتسب: التحويلات الداخلية، سداد البطاقة المتتبعة، العمليات المعلقة، الملغاة، والعمليات قيد المراجعة.
- المستردات تُطرح من تصنيف الشراء الأصلي. التحويلات الواردة ليست دخلاً.
- أي عملية ناقصة البيانات (مبلغ، اتجاه، مبلغ بالريال لعملة أجنبية، تكرار محتمل، تحويل محتمل لنفسك) تذهب لقائمة المراجعة ولا تُخمَّن.
